# 31. 게임 공통 계약

- 담당자: **기획 세션**
- 단계: 0 (G1 착수 전 완료)
- 사용: G1~G6 전원 (읽기 전용). 변경은 기획 세션에 요청

## 1. 어셈블리

| asmdef | 참조 | 담당 |
|---|---|---|
| `VisionToWall.Core` | 기존 | 기획 세션 |
| `VisionToWall.Game` (신규, `02_Scripts/Game/`) | Core, Unity.TextMeshPro | G1, G2, G3, G5 |
| `VisionToWall.Game.Tests` (신규, `02_Scripts/Game/Tests/`) | Game, Core, 테스트 프레임워크 | G1, G2, G3, G5 |
| `VisionToWall.Render`, `.Network`, `.UI` | 기존 (Game 참조 금지) | 해당 세션이 지정 범위만 수정 |

모듈 간 통신은 Core 인터페이스로만 한다. Render, UI는 Game 어셈블리를 몰라야 한다.

## 2. 데이터 흐름

```
[hand_sensor.py]  hand → UDP 9000 ─┐
                  body → UDP 9001 ─┼─ UdpMotionReceiver × 2
[Unity 웹캠 센서] motion → UDP 9000 ┘       │ IPointSource
                                            ▼
                   PlayerInputTracker ── IPlayerInputSource (위치, 모션 강도)
                         │                  │
                         ▼                  ▼
                 GamePhaseMachine ←→ BossCombatController
                  IGamePhaseSource     ICombatStateSource
                         │                  │
             ┌───────────┴──────┬───────────┘
             ▼                  ▼
      Presentation        HUD / F1 패널
      IWallPresentation → MediaWallController
```

- UDP 패킷 형식은 변경하지 않는다. 몸 스트림은 `count` 0 또는 1, `x, y` = 몸 중심, `v` = 몸 이동 속도 정규화 값
- 포트별로 `seq`가 독립이다

## 3. Core 추가 코드 (`02_Scripts/Core/GameContracts.cs`)

```csharp
namespace VisionToWall.Core
{
    public enum GamePhase { MediaWall, Awaken, Combat, Result }
    public enum GameResult { None, Victory, GameOver }
    public enum PlayerPositionSource { None, Body, MotionCentroid }

    public struct PlayerSample
    {
        public UnityEngine.Vector2 position; // 0~1, 원점 좌하단, Mirror 반영 완료
        public bool hasPosition;
        public PlayerPositionSource source;
        public float motion;                 // 0~1, 평활된 모션 강도
    }

    public interface IPlayerInputSource
    {
        PlayerSample Current { get; }
    }

    public interface IGamePhaseSource
    {
        GamePhase Phase { get; }
        GameResult Result { get; }
        float PhaseElapsedSec { get; }
        float AwakenCharge { get; }          // 0~1
        event System.Action<GamePhase> PhaseChanged;
    }

    public enum CombatEventType
    {
        AimStarted, AimLocked, Fired, Dodged, PlayerHit,
        ShieldRaised, ShieldLowered, Parried, BossDefeated
    }

    public struct CombatEvent
    {
        public CombatEventType type;
        public UnityEngine.Vector2 position; // 0~1 화면 좌표
    }

    public interface ICombatStateSource
    {
        float BossHp01 { get; }
        float PlayerHp01 { get; }
        float RemainingSec { get; }
        bool ShieldActive { get; }
        bool IsAiming { get; }
        UnityEngine.Vector2 AimPosition { get; }
        float AimProgress { get; }           // 0~1
        float BossPanDeg { get; }            // v2.1 시리얼 제어용
        float BossTiltDeg { get; }
        event System.Action<CombatEvent> CombatEventRaised;
    }

    /// 구현: Render.MediaWallController (G5). 호출: Game.Presentation
    public interface IWallPresentation
    {
        void SetTheme(float crimsonBlend);   // 0 = 평상시 푸른색, 1 = 전투 붉은색
        void SetAbsorb(float strength, UnityEngine.Vector3 worldCenter); // 0 = 끔
    }
}
```

## 4. config.json 추가 필드

요구사항에 명시된 값은 "요구사항", 나머지는 기획 세션이 정한 시작값이다. 플레이 테스트로 조정한다.

| 필드 | 기본값 | 근거 | 설명 |
|---|---|---|---|
| `udpBodyPort` | 9001 | 설계 | 몸 위치 스트림. 재시작 필요 |
| `awakenChargeSec` | 3 | 요구사항 | 연속 움직임으로 각성까지 걸리는 시간 |
| `awakenMinMotion` | 0.15 | 시작값 | 이 강도 이상이어야 충전 |
| `awakenGraceSec` | 0.5 | 시작값 | 손 방향 전환 때 끊겨도 유지하는 시간 |
| `awakenTransitionSec` | 2 | 요구사항 | Awaken 단계 길이 |
| `combatDurationSec` | 60 | 요구사항 | 전투 제한 시간 |
| `combatAbandonSec` | 10 | 시작값 | 입력이 이만큼 없으면 GameOver (키오스크 복귀) |
| `resultDurationSec` | 5 | 요구사항 | Result 단계 길이 |
| `rearmCooldownSec` | 5 | 시작값 | 복귀 직후 재각성 방지 |
| `aimSec` | 1.5 | 요구사항 | 조준 시간 |
| `aimLockSec` | 0.3 | 시작값 | 조준 후반 고정 구간 (`aimSec`에 포함) |
| `projectileFlightSec` | 0.5 | 시작값 | 발사부터 도착까지 |
| `attackRecoverSec` | 1.5 | 시작값 | 다음 조준까지 간격 |
| `hitRadius` | 0.15 | 시작값 | 피격 반경. 화면 높이 기준, 가로세로비 보정 |
| `shieldThreshold` | 0.8 | 요구사항 | 실드 발동 모션 강도 (F1 "실드 발동 감도") |
| `shieldDurationSec` | 1.5 | 시작값 | 실드 유지 시간 |
| `shieldCooldownSec` | 1.5 | 시작값 | 실드 재사용 대기 |
| `bossMaxHp` | 5 | 시작값 | 패링 성공 횟수 |
| `playerMaxHp` | 5 | 시작값 | 피격 허용 횟수 |

`ConfigService.Sanitize`에 범위 제한을 추가한다. `aimLockSec < aimSec`을 보장한다.
