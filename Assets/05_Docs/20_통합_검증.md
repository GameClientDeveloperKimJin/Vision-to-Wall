## 2. 연결 (`App/AppBootstrap.cs`)

```csharp
void Awake()
{
    var cfg = ConfigService.Load();
    receiver.Initialize(cfg);                    // B
    sender.Initialize(cfg);                      // B
    sensor.Initialize(cfg, sender);              // A → B
    fsm.Initialize(cfg, receiver);               // B → C
    wall.Initialize(receiver, fsm);              // B → C
    panel.Initialize(sensor, receiver, receiver, fsm); // A,B,C → D
}
```
- 씬: `01_Scenes/Main.unity` = `AppBootstrap` + `MediaWall.prefab` + `EngineerPanel.prefab` + Sensor/Network 오브젝트.
- 초기화 순서: 수신 → 송신 → 센서 (수신 포트가 먼저 열려야 첫 패킷 유실 없음).
