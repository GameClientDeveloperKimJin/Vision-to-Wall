## 1. 세션별 통합 (병합 때마다)

기획 세션은 병합 요청을 받으면 다음을 수행한다.

1. `git diff --name-only main origin/feature/game-<이름>`으로 담당 범위 확인
2. `main` 병합·push
3. 세션 문서의 "통합 인계"대로 `AppBootstrap`, `Main.unity` 수정
4. MCP로 컴파일, EditMode, Play 확인
5. `30_게임_개요.md` 4절 갱신, 다음 세션 착수 가능 표시

| 세션 | Main 추가 | `AppBootstrap` 연결 | 상태 |
