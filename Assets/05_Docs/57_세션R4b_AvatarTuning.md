## 1. 진행

1. **대조 녹화 도구**: 같은 시각의 ① 카메라 프레임(손 센서 미리보기와 같은 영상) ② 관절 패킷 ③ Unity 게임 화면을 함께 저장해 나란히 보는 영상(또는 이미지 시퀀스) 생성. 시간 맞춤은 `timestampMs` 기준
2. **자동 어긋남 지표**: 아바타 뼈(상완·전완·대퇴·하퇴)를 화면에 투영한 방향과 카메라 2D 관절 방향(미러 반영)의 각도 차를 시간축으로 기록. 기준을 넘는 구간을 목록으로
3. **사용자 녹화 1회**: 정해진 동작 순서(아래 표)를 사용자가 1~2분 수행. 안내는 "자세 → 동작 → 초" 형식
4. **원인 분류 → 수정**: 구간마다 원인(인식 오류, 깊이 처리, 평활 지연, 각도 제한, 좌우·미러, 구도 밖)을 판정하고 R4 코드에서 고칠 수 있는 것만 수정. 수정 전후 같은 녹화로 지표 비교 (재녹화 없이 재생 가능하게)
5. 인식 자체 오류(MediaPipe)와 구도 문제는 고치지 말고 수치와 함께 보고

| 동작 | 확인 포인트 |
|---|---|
| 팔 옆으로 들기 (좌·우, 천천히·빠르게) | 좌우, 높이, 지연 |
| 팔 앞으로 뻗기 | 깊이 처리 (옆으로 펴지는지) |
| 몸 앞에서 팔 교차, 머리 위 양팔 | 꺾임, 각도 제한 |
| 빠르게 흔들기 | 평활 지연, 떨림 |
| 좌우 이동, 몸 기울이기 | 위치와 몸통 |
| 살짝 앉기 | RT 약점 재확인 |
