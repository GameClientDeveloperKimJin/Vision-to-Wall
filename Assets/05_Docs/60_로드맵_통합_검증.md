**1-1 기본 설정 회귀 (webcam, 장치·날씨 끔, 손 센서 끔)**: 통과
- 자동: Unity 웹캠 동작, 콘솔 에러·경고 0, 미니 캐릭터 숨김, 날씨 Unknown, 장치·가상 조명 꺼짐, 약 400 fps(에디터). 대기 문구는 움직임이 있으면 숨고(`Active`), 비키면 표시
